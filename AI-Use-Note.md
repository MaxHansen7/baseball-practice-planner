# AI Use Note — Baseball Practice Planner

## 1. AI Tool Used
I used ChatGPT by OpenAI to help me create my Baseball Practice Planner website for my AI 101 midterm project.

## 2. Why I Used AI
I used ChatGPT to help me write HTML, CSS, and JavaScript code. I wanted to create a simple website that college baseball players could use to organize extra practice.

AI helped me understand how to build the website and add working features.

## 3. Examples of My AI Prompts
Some of the questions and instructions I gave ChatGPT included:

- "step by step how do i do this"
- "step 6 number 4 what do i do"
- "what do i take a screenshot of"
- "whats my test log?"

I also asked ChatGPT for help adding a Mark Complete button and understanding how to use GitHub.

## 4. What AI Contributed
ChatGPT helped me:

- Create the HTML structure for my website.
- Add CSS to make the website look organized.
- Write JavaScript for adding and displaying practices.
- Add the Mark Complete button.
- Understand how to create a GitHub issue and pull request.
- Organize my testing and documentation.

## 5. What I Did Myself
I personally:

- Chose baseball as the topic for my project.
- Created my GitHub repository.
- Added the website code to GitHub.
- Created an issue and worked with a separate branch.
- Added and tested the Mark Complete feature.
- Created and merged a pull request.
- Tested the website using different practice types, dates, and durations.
- Took screenshots showing my results.
- Created my README and test log.

## 6. How I Verified the AI's Work
I manually tested the website to make sure the features worked correctly.

I completed six tests, including adding practices, marking practices complete, checking that practices stayed separate, checking date order, testing an invalid duration, and refreshing the webpage.

I confirmed that the main features worked. I also discovered that practices disappear when the page is refreshed.

## 7. Limitations
My website does not save practices permanently. When the page is refreshed, the schedule disappears.

The website also does not include user accounts, notifications, or the ability to share schedules with teammates.

AI helped me write the code, but I still needed to test it myself because AI-generated code is not guaranteed to work correctly.

## 8. What I Learned
This project helped me learn how AI can assist with building a website. I learned how to use GitHub, create a pull request, test website features, and document my work.

I also learned that it is important to check AI-generated code instead of assuming it works.

Overall, ChatGPT helped me develop the project, but I was responsible for testing it and making sure it met the assignment requirements.
