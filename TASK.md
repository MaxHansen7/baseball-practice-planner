# TASK.md — Baseball Practice Planner Redesign

## Audience
Alvernia University student-athletes, especially college baseball players who want to organize individual practices.

## Problem
College baseball players have busy schedules with classes, team practices, and homework. It can be difficult to organize extra hitting, fielding, and throwing sessions and track their progress.

## Goal
Improve my existing Baseball Practice Planner website so student-athletes can organize their practices and easily see what they have completed.

## Planned Improvements
1. Add a dashboard showing upcoming practices.
2. Add filters for hitting, fielding, and throwing.
3. Add a progress tracker showing completed practices.
4. Improve the website's layout for phones.

## Acceptance Criteria
1. Users can add a practice with an activity, date, and duration.
2. Users can filter practices by activity type.
3. Users can mark practices complete and see their progress update.

## Testing Plan
I will test all three acceptance criteria, check the website on a phone-sized screen, test keyboard navigation, and make sure the website handles missing or invalid information.

I will also ask a classmate to try adding and completing a practice. I will use their feedback to make one improvement and test the website again.

## AI Agent Plan
I will use an AI coding agent to help improve the website, suggest changes, and troubleshoot problems. I will review the suggestions, decide which changes to keep, and test the final website myself.

## Scope
I will keep the project simple and use my existing GitHub Pages website. I will not add paid APIs, user accounts, or complicated features.
