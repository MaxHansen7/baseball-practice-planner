# AI Use Note — Baseball Practice Planner

## AI Tool Used
I used ChatGPT to help plan, build, troubleshoot, and test my Baseball Practice Planner website for my AI 101 midterm project.

## Purpose
My goal was to create a simple website for college baseball players to organize individual hitting, fielding, and throwing practices.

## Initial AI Prompt
Task: Plan a portfolio website.

Audience: College baseball players who want to organize extra practice.

Goal: Create a simple website to help players plan and track baseball practice.

My supplied information: Players can add hitting, fielding, or throwing activities, choose dates and durations, and mark activities complete.

Constraints: Keep the website simple and easy to use because I have limited coding experience.

Output format: A website plan with main features, a simple layout, and steps to build it.

## Follow-Up AI Prompt
can you add more to my baseball practice planner mid term

## What AI Contributed
ChatGPT helped me plan the website layout, develop HTML, CSS, and JavaScript code, and troubleshoot problems while building the project.

AI also helped me understand how to organize the website files, publish the project using GitHub Pages, and document my testing.

## What I Changed
I worked on improving the website by adding a Mark Complete feature. This allows players to mark practices as finished and see a visual change in the schedule.

I also tested and adjusted the project throughout development.

## What I Personally Verified
I tested the live GitHub Pages website to confirm that:
- Players can add practices.
- Invalid durations are rejected.
- Multiple practices can be added.
- The form can be submitted using the keyboard.
- The website works on an iPhone-sized screen.
- The Mark Complete button changes the appearance of a completed practice.

## Known Limitations
Practices are not permanently saved after refreshing the webpage. The website also does not have user accounts, team sharing, or reminders.

## AI Responsibility
I reviewed the AI-assisted work, tested the website myself, and documented the results. I understand that I am responsible for checking the accuracy and functionality of my project.
